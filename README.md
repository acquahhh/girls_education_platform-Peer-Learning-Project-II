# Girls Education Sponsorship & Mentorship Platform

A menu-driven command-line application (Python + MySQL on Aiven) that manages students, sponsors, mentors, and their assignments in support of girls' education. Built with a modular, layered architecture: menus → services → database, with domain models in between.

Peer Learning Project II — BSE Year 1, Trimester 2, African Leadership University.

## Features

- **Student Management** — register, view, search, update, delete students.
- **Sponsor Management** — register, view, search, update, delete sponsors.
- **Mentor Management** — register, view, search, update, delete mentors.
- **Assignments** — match sponsors and mentors to students, prevent duplicates, view and remove assignments.
- **Reports** — totals for students, sponsors, mentors, and counts of sponsored vs. unsponsored students.
